# LTX Alpha Refine

这是面向白底人物视频的 LTX Alpha Gen 手部边缘修复代码，以及运行时优化研究记录。

主要流程：LTX 提供粗 Alpha → 当帧手部检测 → 按原图证据修正 trimap → 局部 ViTMatte → 限定区域回写和白底去色 → 有条件恢复误删的白色前景。相邻帧只帮助确认当帧已有的检测框，不搬运蒙版，因此不会通过时序平滑增加滞后。

公开接口显式接收模型目录，已与参考实现核对。推理数学和阈值保持原样，整理后的像素一致性结果记录在 `docs/validation.json`。

这不是新训练的 LTX 权重，也不是 Lightricks 官方版本。LTX、Alpha Gen、社区两步蒸馏、ViTMatte 和手部检测模型的贡献分别署名。代码包不包含权重、权重缓存、人物素材或内部部署配置。

完整优化流程约 60 秒的结果属于集成管线。本仓库的 CLI 只处理已有的源图和 Alpha，不能把它自身的运行时间当成全流程时间。13 个角色、15 段视频是开发/回归集，不等于已证明对任意人物泛化。

安装、模型来源、命令和限制见 [README](README.md)。通用加载优化适合向 LTX 上游提出独立贡献，具体边界见 [提案](docs/UPSTREAM_PROPOSAL.md)。目前这是可供审阅的开源候选包，尚未声称获得上游采纳。
